# Руководство пользователя

## Назначение программы

Программа предназначена для учёта успеваемости студентов.

## Основные функции

- Добавление студента.
- Редактирование данных студента.
- Удаление студента.
- Просмотр списка студентов.

## Порядок работы

1. Запустите программу.
2. Выберите нужную операцию.
3. Введите данные.
4. Сохраните результат.

**Важно:** перед удалением записи убедитесь, что она больше не нужна.

Дополнительная информация: [официальный сайт pandoc](https://pandoc.org).
